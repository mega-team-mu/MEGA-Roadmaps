## 📖 Overview

A 38-week computer science roadmap that takes you from your first line of code to data structures and algorithms, using C++. You start with programming fundamentals (variables, conditions, loops, arrays, functions, recursion and the STL), move on to object-oriented programming (classes, inheritance, polymorphism, exception handling and pointers), and finish with data structures (linked lists, stacks, queues, trees, heaps, tries and hashing) and algorithms (sorting, binary search, graphs and dynamic programming). Every week combines video tutorials with practice problems, and the Entry and Intermediate levels each end with a project. Suitable for beginners with no programming experience.

**Learning path:** 🌱 Entry → 🚀 Intermediate → 🏆 Advanced  
**Total duration:** 38 weeks

## 🗂️ Levels

| Level | Weeks | Goal |
|:------|:------|:-----|
| 🌱 [Entry](01-entry/README.md) | 13 | Learn programming fundamentals in C++ (variables, conditions, loops, arrays, functions, structs, recursion and the STL) and practice them by solving problems. |
| 🚀 [Intermediate](02-intermediate/README.md) | 8 | Learn object-oriented programming in C++ (classes, constructors, inheritance, polymorphism, exception handling and pointers) and apply it in a project. |
| 🏆 [Advanced](03-advanced/README.md) | 17 (11 + 6) | Learn data structures (linked lists, stacks, queues, trees, heaps, tries and hashing) and core algorithms (sorting, binary search, graphs and dynamic programming) and use them to solve problems. |
