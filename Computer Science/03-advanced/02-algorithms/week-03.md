## 📚 Topics
1. Recursion and Binary Tree Revision

> A recursive function is a function that calls itself to solve a smaller sub-problem of the same type. Every recursion needs a base case to stop and a recursive case that moves toward it.
>
> A binary tree is a tree where each node has at most two children (left and right). A node consists of a value, a left pointer, and a right pointer.
>
> In a binary tree we traverse it recursively:
> - Visit the current node, go left, go right.
