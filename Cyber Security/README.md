## 📖 Overview

Cybersecurity is the practice of protecting computer systems, networks, applications, data, and users from unauthorized access, misuse, disruption, modification, or destruction. It is not just one skill or one tool: it combines technology, risk management, operations, and human awareness, and it includes both defensive and offensive work.

**The CIA Triad.** The foundation of cybersecurity:

- **Confidentiality:** protecting information from unauthorized access (encrypting data, restricting permissions, using MFA).
- **Integrity:** making sure data cannot be altered or tampered with without detection (hashing, access control and logging, secure development).
- **Availability:** making sure systems and services are available when needed (DDoS protection, backups, resilience).

**Red, Blue and Purple Teams.**

- **Red Team** is offensive security: simulate attackers and find weaknesses before real attackers do (penetration testing, exploit research, social engineering assessments, adversary emulation).
- **Blue Team** is defense: detect, block, investigate, and respond to attacks (SOC, threat hunting, incident response, vulnerability management, hardening).
- **Purple Team** is where Red and Blue work together to improve security by testing detections and defenses in a realistic way.

**Recommended learning order.**

1. Networking and Linux
2. Windows and system basics
3. Python and Bash scripting
4. Cybersecurity fundamentals and the CIA Triad
5. Cryptography
6. Web, cloud, and application security basics
7. Choose a track: Red Team or Blue Team
8. Practice through labs and real-world scenarios
9. Build projects and create a portfolio
10. Keep learning and stay updated

This roadmap starts with the Entry level, then lets you choose a specialization: **SOC** (Blue Team) or **Penetration Testing** (Red Team).

**Learning path:** 🌱 Entry → 🛡️ SOC or 🎯 Penetration Testing  
**Total duration:** 9 weeks (Entry) + 11 weeks (one specialization)
