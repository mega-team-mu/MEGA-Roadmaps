# 📘 Week 05 · Recon, Scanning & Enumeration (Nmap)

> **Track:** Cyber Security  ·  **Level:** 🎯 Penetration Testing

## 📚 Topics
1. Information Gathering (Passive & Active Recon): footprinting, social networks OSINT, DNS, WHOIS, subdomains, technology fingerprinting
2. Scanning (Nmap): host discovery, port scanning, service/version detection, OS detection, NSE scripts
3. Enumeration: web directories, SMB/NetBIOS, FTP, SSH, MySQL, and other services
4. Vulnerability Assessment: vulnerability assessment vs penetration test, scanners, false positives, CVSS scoring
