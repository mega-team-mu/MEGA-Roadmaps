## 📖 Overview

A 20-week UI/UX design roadmap that takes you from the fundamentals of design to portfolio-ready work. You start with design basics, Figma and user research, move on to the full UX/UI process from problem definition to an interactive prototype, and finish with professional practice: design systems, developer handoff, usability testing, motion, case studies and a portfolio. Suitable for beginners with no design experience who want to work as UI/UX designers.

**Learning path:** 🌱 Entry → 🚀 Intermediate → 🏆 Advanced  
**Total duration:** 20 weeks

## 🗂️ Levels

| Level | Weeks | Goal |
|:------|:------|:-----|
| 🌱 [Entry](01-entry/README.md) | 5 | Understand the difference between UI, UX and Product Design, learn Figma and the core visual design principles (color, typography, grids, spacing and layout), and run a basic user research phase to design a small app. |
| 🚀 [Intermediate](02-intermediate/README.md) | 7 | Follow the full UX/UI design process from problem definition to an interactive prototype (personas, user journeys and flows, information architecture, wireframes, high-fidelity and responsive design, and a reusable design system) and complete an end-to-end project. |
| 🏆 [Advanced](03-advanced/README.md) | 8 | Work at a professional level: build scalable design systems with design tokens, prepare designs for developer handoff, validate them with usability and A/B tests, add interaction and motion, and present your work through a case study and a portfolio. |
