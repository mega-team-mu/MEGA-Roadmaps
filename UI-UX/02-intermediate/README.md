> **🎯 Goal:** Follow the full UX/UI design process from problem definition to an interactive prototype (personas, user journeys and flows, information architecture, wireframes, high-fidelity and responsive design, and a reusable design system) and complete an end-to-end project.  
> **⏱️ Duration:** 7 weeks  
> **📋 Prerequisites:** Completion of the Entry level

> [!NOTE]
> Tasks in this level refer to “your project”. Whether this is one project carried across levels or a new project per level is _to be decided_.
