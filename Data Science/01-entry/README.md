## ✅ Exit Check

By the end of Week 20, every Entry member should be able to, unprompted:

- Write working Python (including a simple class/OOP) without copying from a tutorial
- Query and JOIN multiple tables in SQL
- Take a raw, messy dataset and clean it — with a written reason for every decision made
- Build at least 3 chart types and explain what each one shows about the data
- Train **and** evaluate both a Linear Regression and a Logistic Regression model, and explain the metric used (RMSE / Accuracy) in plain language
