## ✅ Exit Check

By the end of the Track Project (Week 18), every Advanced member should be able to, unprompted:

- Take a baseline model and measurably improve it through tuning (e.g. GridSearchCV), with the improvement documented
- Build and evaluate a real Deep Learning model, including at least one regularization technique
- Explain their track's core workflow end-to-end (e.g. the RAG pipeline, or the CI/CD flow) without notes
- Ship a complete, deployed track project with a professional README that someone outside the team could follow
