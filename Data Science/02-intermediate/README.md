## ✅ Exit Check

By the end of Week 20, every Intermediate member should be able to, unprompted:

- Engineer features (encoding, scaling, feature selection) on a new dataset
- Train and compare at least 3 model types (e.g. Tree, Random Forest, KNN) using cross-validation
- Choose the right evaluation metric for a given problem (Accuracy vs. Precision/Recall vs. F1) and justify the choice
- Apply K-Means and PCA and interpret the result in plain language, not just run the code
- Deploy at least one model as a working Streamlit app
- Describe — in their own words — how a neural network works, and what NLP, Computer Vision, Data Engineering, and MLOps each actually involve day-to-day
