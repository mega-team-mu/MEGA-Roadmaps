## 📖 Overview

A 12-month plan to help Mega Team members learn frontend development, step by step, in three levels: Entry, Intermediate and Advanced. Each level tells you what to learn, which resources to use, and which projects to build. By the end, you'll have real projects in your portfolio and the skills to apply for frontend jobs.

You'll start with the basics (HTML, CSS) and finish building real, production-style apps. Most lessons are in Arabic (Elzero Web School and others), and each topic also has an optional English course (marked 🌍) if you want to go deeper. Study 1-2 hours a day, review what you learned every week, and push every project to GitHub with its own README (what it does, screenshots, tech used, how to run it).

> [!NOTE]
> **Arabic or English?** Pick ONE per topic. The Arabic playlist is the default — use it unless you want extra depth, in which case switch to the 🌍 English course instead (not both).

> [!NOTE]
> The 🌍 Udemy courses are paid (they go on frequent sales). Members who prefer a fully free path should stick to the Arabic playlists; members who want extra portfolio projects (Omnifood, Mapty, Forkify) and don't mind paying should pick the 🌍 alternative for that topic.

**Learning path:** 🌱 Entry → 🚀 Intermediate → 🏆 Advanced  
**Total duration:** 12 months (50 weeks)

## 🗂️ Levels

| Level | Weeks | Goal |
|:------|:------|:-----|
| 🌱 [Entry](01-entry/README.md) | 12 (3 months) | Learn the basics of web technologies and build simple static websites. |
| 🚀 [Intermediate](02-intermediate/README.md) | 16 (4 months) | Move from static websites to dynamic, interactive apps, focusing on JavaScript, React, and the tools around them. |
| 🏆 [Advanced](03-advanced/README.md) | 22 (5 months) | Learn production-level tools and build full, complete applications, focusing on TypeScript, Next.js, and performance/deployment. |
