### 🏗️ Project: Landing Page
_HTML + CSS · builds up over Weeks 2-6_

- A one-page site for a fictional product or service (a gym, a coffee shop, an app — pick anything).
- Must include: a hero section (headline + image + call-to-action button), a features/services section, a pricing or testimonials section, a working contact form, and a footer.
- Redo its layout as you learn new tools: first with basic CSS, then Flexbox, then CSS Grid, then Tailwind — same content, better code each time.
- Must be fully responsive (looks good on mobile, tablet, and desktop).
