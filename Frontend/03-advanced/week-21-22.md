### 🏗️ Project: Kanban Board App
_Weeks 21-22 · Trello-style project management tool_

- Boards → Lists (columns like "To Do", "In Progress", "Done") → Cards (tasks), each card with a title, description, due date, and labels.
- **Drag and drop** cards between lists, and reorder lists themselves (use a library like `@dnd-kit` or `react-beautiful-dnd`).
- Multiple boards per user, so they can manage more than one project.
- Authentication required to create/edit boards; each user only sees their own boards (or boards they're invited to, for extra credit).
- Backend: **Prisma + PostgreSQL** to model boards, lists, cards, and their order/position. Use **TanStack Query** with optimistic updates so drag-and-drop feels instant even while saving to the server.
- This one is a strong portfolio piece specifically because drag-and-drop + ordered nested data is genuinely tricky to get right — it shows more real skill than a typical feed-and-likes app.

### 🏗️ Project: Real-Time Chat App
_Weeks 21-22_

- One-to-one or group chat with messages appearing instantly.
- Show when a user is online/offline.
- Store and load previous messages when you reopen a chat.
- Backend: **Prisma + PostgreSQL** to persist users, conversations, and messages; add **WebSockets** (e.g., Socket.io on a small Node/Express server) on top for the instant/real-time part, and use **TanStack Query** to load the message history for each conversation.
