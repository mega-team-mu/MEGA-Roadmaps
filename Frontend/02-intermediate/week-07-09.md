### 🏗️ Project: Blog App
_React · Weeks 7-12_

- Show a list of blog posts (title, short excerpt, cover image) fetched from a public API such as JSONPlaceholder.
- Clicking a post opens its full content on its own page (dynamic route/detail page), including a "back to all posts" link.
- Add client-side search (by title) and filtering by category/tag.
- Add pagination or "load more" once there are many posts.
- Fetch and cache the posts with **TanStack Query** instead of plain `fetch`/`useEffect` — you get loading/error states, caching, and refetching for free, which is exactly how this is done in real jobs.
- Keep small UI state (search text, selected category, current page) in local component state or a light **Zustand** store — no need for Redux here.
