## 📖 Overview

A 21-week Flutter roadmap, in three progressive levels, that takes you from your first lines of Dart to building production-ready mobile apps. You start with the foundations (Dart, object-oriented programming, SOLID principles and Flutter widgets), move on to working with APIs and managing state with Bloc and Cubit, and finish with Firebase, Clean Architecture, advanced Flutter topics and clean code. Each week points you to the exact videos to watch. Suitable for beginners with no mobile development experience.

**Learning path:** 🌱 Entry → 🚀 Intermediate → 🏆 Advanced  
**Total duration:** 21 weeks

## 🗂️ Levels

| Level | Weeks | Goal |
|:------|:------|:-----|
| 🌱 [Entry](01-entry/README.md) | 7 | Learn the foundations: the Dart language, object-oriented programming, SOLID principles and the basics of building Flutter apps with widgets. |
| 🚀 [Intermediate](02-intermediate/README.md) | 5 | Build data-driven apps and apply what you learned in projects: work with APIs and manage app state with Bloc and Cubit. |
| 🏆 [Advanced](03-advanced/README.md) | 9 | Build production-ready apps: use Firebase, structure your code with Clean Architecture, learn advanced Flutter topics and write clean code. |
