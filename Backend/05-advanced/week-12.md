# 📘 Week 12 · API Reliability & Protection

> **Track:** Backend  ·  **Level:** 🏆 Advanced

## 📚 Topics
1. Rate Limiting in ASP.NET Core
2. Rate Limiting Policies & Middleware
3. HTTP Resilience

> 💡 Focus on two different aspects of API reliability: controlling incoming requests with Rate Limiting, and handling failures when calling external services using HTTP Resilience.
>
> Start by applying a simple rate-limiting policy to one API endpoint. Then configure an `HttpClient` with timeout, retry, and circuit-breaker strategies to handle transient failures.
>
> Focus on understanding when each technique is useful rather than applying every policy to every request.
