## 📖 Overview

> 🌱 **Start with curiosity, not perfection.**
>
> This roadmap is a journey: focus on understanding, practicing and improving step by step.

A 37-week .NET Backend roadmap that takes you from web basics and C# to building and deploying production-ready ASP.NET Core applications. You start with an introduction to Backend and .NET, web basics and Git, then build a foundation in C# (OOP, collections, delegates, async, SQL, SOLID). Next come LINQ, Entity Framework Core and design patterns, followed by ASP.NET Core (MVC, Web API, Identity and JWT security). The advanced part covers architecture, testing, caching, real-time apps, background jobs, configuration, health checks and API reliability, then deployment with Azure and Docker, and how to use AI in your development workflow. Many weeks end with a hands-on task. The levels follow the roadmap's own sections (Entry, Beginner, Intermediate 1 and 2, Advanced, Deployment & Production, AI for Developers), and the original week numbers of each section are kept.

**Learning path:** 🌱 Entry → 🌿 Beginner → 🚀 Intermediate 1 → 🌐 Intermediate 2 → 🏆 Advanced → ☁️ Deployment & Production → 🤖 AI for Developers  
**Total duration:** 37 weeks
