> **🎯 Goal:** Work with data in C#: learn LINQ, Entity Framework Core and design patterns, and build a small database-driven C# application.  
> **⏱️ Duration:** 5 weeks (Weeks 9-13)  
> **📋 Prerequisites:** Completion of the Beginner level

## 🗓️ Weeks

| Week | Title |
|:-----|:------|
| [Week 09](week-09.md) | LINQ Fundamentals |
| [Week 10](week-10.md) | LINQ Advanced & C# Modern Features |
| [Week 11](week-11.md) | Entity Framework Core Fundamentals |
| [Week 12](week-12.md) | EF Core Advanced |
| [Week 13](week-13.md) | Design Patterns |

## ✅ By the End of This Level

By the end of this level, you should be comfortable with:

- C# fundamentals
- OOP
- Collections & Generics
- Delegates & Events
- Async/Await
- SOLID
- SQL Server
- LINQ
- Entity Framework Core
- Git & GitHub

You should also be able to build a **small database-driven C# application** and understand the fundamentals needed to start building real .NET Backend applications.
