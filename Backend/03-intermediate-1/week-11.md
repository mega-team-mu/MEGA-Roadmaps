## 📝 Assignment
- [ ] Employee & Project Management System (EF Core Fundamentals)

Build an **Employee & Project Management System** using **C#, Entity Framework Core, and SQL** The goal is to learn how to create a database using the Code First approach and perform basic database operations through EF Core.

Create the following domain classes:

- **Department:** Id, Name.
- **Employee:** Id, Name, Email, Salary.
- **Project:** Id, Name, Description.

The application should allow users to:

- **Add** employees, departments, and projects.
- **Edit** employee, department, and project data.
- **Delete** employees, departments, and projects.
- **Display** lists of employees, departments, and projects.
- Use the **Code First** approach.
- Create and apply the initial database migration.
- Implement basic CRUD operations using EF Core.
