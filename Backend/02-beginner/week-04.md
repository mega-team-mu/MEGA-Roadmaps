## 📝 Assignment
- [ ] Notification System (Delegates & Events)

This project is a simple **Notification System** built using **delegates, events, anonymous methods, and lambda expressions** in C#. It allows users to subscribe to different notification channels and receive alerts when new messages are published.

**Key Features:**

- Subscribe or unsubscribe from channels like **News**, **Sports**, or **Promotions**.
- Publish notifications to specific channels.
- Notify all users subscribed to a channel using **events**.
- Use **delegates** to define notification handlers.
- Store message history with timestamps.
- Add a **Do Not Disturb** option to prevent users from receiving notifications.

Focus on understanding how **delegates and events** enable communication between different parts of the application.
