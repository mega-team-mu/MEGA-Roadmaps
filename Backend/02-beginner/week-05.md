## 📝 Assignment
- [ ] Asynchronous Notification System

Extend the **Notification System** from Week 4 by introducing **asynchronous programming** to simulate real-time notification delivery.

**Key Features:**

- Deliver notifications asynchronously using `async` and `await`.
- Simulate notification delays to represent real-world delivery.
- Allow multiple notifications to be processed without blocking the main application flow.
- Keep a message history with timestamps.
- Add a console alert using `Console.Beep()` when a notification is received.
- Add an **Unsubscribe All** option.
- Add an admin command to view active users.

Focus on understanding how **asynchronous programming** improves responsiveness and how `async` and `await` work in C# applications.
