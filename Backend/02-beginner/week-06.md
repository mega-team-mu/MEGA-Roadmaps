## 📝 Assignment
- [ ] Database Design (ERD & Mapping)

Musicana Records wants to store information about musicians, instruments, albums, and songs in a database. Your task is to design a conceptual schema for the system and map it to a relational schema.

The database should store the following information and relationships:

- **Musicians:** Each musician has an ID, name, address (street and city), and phone number.
- **Instruments:** Each instrument has a unique name and a musical key (e.g., C, B-flat, E-flat).
- **Albums:** Each album has a unique title, copyright date, and album identifier.
- **Songs:** Each song has a unique title and an author.
- **Musician–Instrument Relationship:** Each musician may play multiple instruments, and each instrument may be played by multiple musicians.
- **Album–Song Relationship:** Each album contains multiple songs, and each song must belong to one album.
- **Musician–Song Relationship:** Each song is performed by one or more musicians, and each musician may perform multiple songs.
- **Album Producer:** Each album has exactly one musician as its producer, and a musician may produce multiple albums.
