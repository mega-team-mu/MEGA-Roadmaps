# 📘 Week 01 · HTTP & ASP.NET Core Introduction

> **Track:** Backend  ·  **Level:** 🌐 Intermediate 2

## 📚 Topics
1. How the Web Works , Client & Server, HTTP
2. MVC Introduction

> 💡 Before building APIs, make sure you understand what happens when a client communicates with a Backend.
>
> Focus on understanding HTTP requests and responses and how ASP.NET Core receives and processes them.
>
> MVC is important for understanding how ASP.NET Core applications are structured.
>
> You don't need to become a Frontend Developer here. The goal is to understand how Controllers, Models, Views, Routing, and HTTP work together.

## 📝 Assignment
- [ ] Student Management System (ASP.NET Core MVC)

Build a simple **Student Management System** using **ASP.NET Core MVC**. The application displays a list of students and allows users to view the details of each student.
**Create a Student model with Id, Names, Address, and Img, and a static StudentList to store multiple students.**

**Implement a** StudentController **with** Index() **to display all students and** Details(id) **to view a single student’s details.**
